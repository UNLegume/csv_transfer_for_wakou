# 注文・CSV出力の状態モデル

## 基本方針

Shopifyは注文データの正本です。このアプリはShopifyへ注文・商品・発送状態を書き込みません。
アプリ内で永続化するのは、個人情報を含まないCSV出力履歴だけです。

## CRUDの責務

| 対象 | Create | Read | Update | Delete |
|---|---|---|---|---|
| Shopify注文 | 対象外 | 注文取得時に読取り | 対象外 | 対象外 |
| 注文プレビュー | 注文取得時に15分間だけ作成 | 「未出力の注文」タブ | 配送会社の一時変更と選択状態 | CSV出力成功後に対象注文だけ削除 |
| CSV出力履歴 | CSV生成成功時に追記 | 「出力済み一覧」タブ | 更新しない。再出力は新しい履歴として追記 | 削除しない |

## 画面の状態遷移

1. 「Shopifyから注文取得」で一時プレビューを作成する。
2. 過去に出力していない注文だけを「未出力の注文」に表示する。
3. チェック状態とヤマト／佐川の変更はブラウザ内の一時状態として保持する。
4. 複数注文を選択した場合、ヤマトボタンはヤマトに設定された注文だけ、佐川ボタンは佐川に設定された注文だけを出力する。
5. 一方のCSVを出力しても、もう一方の配送会社に属する選択状態は維持する。
6. CSVレスポンスと履歴保存の両方が成功した注文だけを未出力一覧から除外する。
7. 出力記録は「出力済み一覧」へ即時反映する。
8. 注文を再取得しても、出力済み注文は未出力一覧へ戻さない。

## 配送会社変更

- 自動判定結果は参照値として保持する。
- 出力先を変更するときだけ変更理由を必須にする。
- 「要確認」の注文には初期の出力先を設定しない。
- 配送会社の変更はShopify商品や注文へ書き戻さない。

## 出力履歴

保存する項目：

- バッチID
- Shopify注文ID
- 注文番号
- 配送会社
- 出力日時
- 再出力理由

保存しない項目：

- 氏名
- 住所
- 郵便番号
- 電話番号
- 商品明細

履歴は監査記録として追記専用にし、画面から削除・編集しません。
